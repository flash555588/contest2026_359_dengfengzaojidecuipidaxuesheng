# Grok Ball 与 ESPClaw

首页采用已审核的 A 版：96 px 黑色马赛克球体（4 px 方块、暗色缝隙、浅色眼睛），中心位于卡片上半区的 (76, 65)，上半区高 89 px，名义底部遮挡 24 px。ESPClaw 在当前 AI 输出框左侧使用原先的 48 px 迷你像素球，保留原始明暗、表情姿态和彩带，不使用首页的马赛克/正面覆盖。透明视口 64 × 64，随输出框滚动，离开可见区域时暂停。聊天页只保留一个组件，消息重建不会重启它或重复播放完成动画。左栏与标题恢复原有布局，保留发送、停止、输入、预览、保存和返回流程。

`glass_grok.c` 是父容器拥有的原生组件。每个组件使用独立的 QuickJS 上下文，加载同一个固定版本的 Grok 引擎；与快应用运行时不共享全局对象、定时器或控件注册表。父容器删除时释放定时器、脚本上下文和轮廓内存。桌面面板覆盖首页时暂停首页小球；减少动效设置保留静态表情切换。渲染复用有边界校验的 polygon 实现，未传像素参数的原有快应用保持原绘制路径。

聊天服务在互斥锁下提供精简、只读的状态投影，不复制聊天历史，不触发网络请求。连接、思考、回复和工具活动直接来自流事件；心跳及 token 用量事件不会覆盖当前活动。语音聆听来自实际语音服务的 active/phase。

| 实际状态 | 表情 ID |
|---|---|
| 待机 | 02 |
| 请求排队 | 31 |
| 连接、载入 | 36 |
| 推理 | 30 |
| 回复正文 | 39 |
| 处理草稿、语音收尾 | 32 |
| 语音聆听 | 35 |
| 完成 | 33，播放一次后回到待机 |
| 请求失败 | 34 |
| 停止、取消 | 41 |

入场彩带通过激活后的引擎状态切换触发，不伪造成功状态。重新打开已完成的历史不会重播庆祝。执行和解析保护使用与快应用相同的共享限值，逐帧绘制仍由适配层合作让出 UI 线程。源引擎及 MIT 许可未修改。

生成组件资源：`python tools/generate_grok_embedded.py`。使用本机 prepared apps / LVGL / QuickJS 缓存，可运行 `tools/test_grok_embedded.py` 和带 `tests/render_grok_espclaw.c` 的 `tools/render_all_ui.py`，检查真实运行时、状态切换、退出释放和原生截图。服务投影另由 `tests/chat_activity_host.c` 使用真实流事件验证。

验证边界：原生主机检查使用离线服务数据；RV32 检查编译受影响的目标文件。64 位 ASan 主机的 QuickJS 栈保护为 256 KiB，RV32 为 16 KiB，因此主机检查不证明实板栈余量、性能或联网行为。本次未链接新整包固件、未烧录，保留后续用户批准后的实板验证。
