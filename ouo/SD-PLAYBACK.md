# Grok Ball SD 播放

首页、聊天头像和独立应用均使用 `glass_grok.c` 原始像素帧播放器。固定版本的 SDK 仅用于电脑离线生成素材；设备不加载 SVG 引擎、不计算轮廓，也不解码 PNG/JPEG。

素材目录 `/sdcard/grok/`，五个素材包约 585 MiB，与生成时的 `manifest.json` 配套。首页白/黑球直径 96 px，聊天头像 48 px；独立应用保留上游视角并最近邻放大。首页保持 A 方案、右向、底部四分之一遮挡。

每种表情 80 帧、每帧 100 ms，八秒循环。32 种公开表情 ID 不变，独立应用另有自旋和九方向注视素材。动画为有限录制循环，注视为九方向；不再实时随机生成新姿势或彩带轨迹。

后台线程读取 SD，前台交换双缓冲 LVGL 图像。96 px 球缓冲合计 96 KiB，48 px 头像 24 KiB，另有线程栈和少量对象。遮挡、隐藏和表情选择弹窗暂停播放；减少动效模式只更新静态帧。表情切换丢弃过期读帧；退出时等待线程释放文件和缓冲。

素材头 `GROKSD1`、版本 1，包含尺寸、周期、帧大小、状态表。每帧为 RGB565 平面和 A8 透明度平面，未经压缩。设备校验头、状态 ID、长度、偏移。缺失素材显示提示并低频重试，不回退实时 SVG。

`tools/upload_grok_sd.py` 私下通过 USB 取得设备页面的短期配对码，用原有文件接口临时写入并原子重命名，随后核对设备端流式 SHA-256。配对信息仅在进程内。实板记录在工作区 `output/integrated-flash-20261014/`。

`tools/render_grok_sd.py` 的 `--snapshot` 指定已批准原生渲染器的归档目录。固定 SDK 为 MIT，SHA-256 `72960b6398032d45c8e4ca4386dfb2a9b6f286d67af0d3c2692dcffeab273fbb`。

`tools/test_grok_sd.py` 用 ASan/UBSan 验证全部表情/配色、读取、注视、自旋、隐藏/减少动效、缺失/损坏素材、读取中退出。服务事件到表情的映射沿用 `glass_grok_state.c`。
