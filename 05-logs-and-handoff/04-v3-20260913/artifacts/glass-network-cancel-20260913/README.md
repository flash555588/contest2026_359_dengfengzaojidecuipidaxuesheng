# openvela 桌面网络取消候选 · 2026-09-13

Home Assistant 页面退出现在只发出取消请求，不执行 socket 操作或循环等待线程。
原工作线程负责关闭连接和释放响应；旧结果不会交给重新打开的页面。尚未刷机。

连接、发送和接收使用非阻塞 socket，以最多 100 ms 的 poll 间隔检查取消，
并共用 5 秒单调时钟预算。支持短读写和 EINTR/EAGAIN，发送零字节会报错。
DNS 返回前不分配 64 KiB 响应缓冲区；请求内容保持独立有效，直到原线程结束。
同时只执行一个请求，取消尚在收尾时新请求返回忙状态。

DNS 系统调用本身仍不可强制中断，因此它可能晚于预算返回；此时界面不等待，
但旧线程会保留必要状态。取消不能撤销服务端已经执行的控制操作。

## 相机后续边界

本候选没有修改相机退出代码或驱动。已确认采集 DQBUF 尊重 O_NONBLOCK；
CSI 停流可能交给 LPWORK，设备关闭时还会同步等待该工作结束。因此
STREAMOFF 返回不能单独作为释放显示页或恢复 LVGL 绘制的依据。

后续需要分开处理 UI 对象和硬件资源的所有权，覆盖延迟停流、退出等待、
停流失败和再次启动；不得从工作线程删除 LVGL 对象，或提前释放 DMA
仍可能使用的缓冲区。v3 冷启动、真实网络、相机与长期 CPU/内存恢复仍需实板验证。
