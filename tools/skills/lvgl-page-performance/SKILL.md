# LVGL 页面生命周期与性能

在含 `app/espdl-quickapp/` 的项目根读 `AGENTS.md`。先确认实际 Makefile、include、生成资源及运行入口，区分历史源码、生成副本和正在执行的页面。删掉未编译文件不能改善当前负载。

## 找到实际浪费

对用户报告的页面采样 CPU、任务、读盘、文字写入、控件/定时器/动画数量；标明双核 CPU 的统计口径。保留用户明确要求的小球、朝向、主题和视觉效果，不以移除功能冒充优化。

- 相同文字/样式/位置跳过重复 LVGL 写入，先用实际调用计数验证。QuickJS 字符串转换可能删除并复用控件，转换后重新验证代次；省略号状态下 LVGL 可能改写文字缓冲区，不能只比较失真的字符串。
- `lv_obj_is_visible()` 不代表未被兄弟对象遮住。仅在完整、不透明、无变换的全屏覆盖可证明时暂停下层绘制；部分弹窗、半透明、圆角或变换保守处理，保留上层浮球。
- 页面被遮挡时延后文字、图表、动画读帧和构建，后台连接、请求完成、保存、取消、采样和所有权交接继续。恢复时补绘最新状态，初次打开即可绘制。
- 暂停已有动画/定时器即可达到目标时，不新增隐藏轮询器。资源缓存要有容量和回收边界；先证明读盘是瓶颈，不默认整包常驻 PSRAM。

## 生命周期与视觉一起验证

执行打开、覆盖、恢复、退出，预热共享字体/缓存后比较每轮基线。统计全部 LVGL 定时器，包括暂停项，另统计控件和动画。常驻桌面、顶栏、字体缓存不应被当成页面泄漏删除。

对修改涉及的两套主题、普通/减少动效及临时弹窗验证。截图前推进延迟构建所需帧数；池化控件需检查创建顺序和 z-order。对共用 UI 路径检查缺失控件，如大球页没有草稿标签。

读取 [references/project.md](references/project.md) 选择已有真实 LVGL/QuickJS 夹具和资源生成链。宿主减少的调用数不能换算成整机 FPS 提升；关闭泄漏检测的 ASan 结果不能称为完整堆泄漏通过。
