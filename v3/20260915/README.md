## 源码分层

- `source/`：从当前隔离相机构建树导出的桌面、C6、ESP-Claw、相机应用及 P4 板级／架构源码。
- `04-v3-20260913/camera-usb-fix/overlay/`：相机第 11 版累积修复，包含 USB Host／UVC 和此前网络、存储、BLE 修复。
- `04-v3-20260913/espclaw-voice/overlay/`：在相机第 11 版上开发的语音输入，**开发中**。
- `diagnostics/`：原有隔离构建脚本、协议测试、语音宿主测试和验证工具。
- `SOURCE-MANIFEST.json`：源码哈希、相机／语音镜像身份和导出范围。
- `PUBLICATION-SHA256SUMS`：本次 Git 快照文件的哈希清单。

覆盖顺序是匹配的 openvela/NuttX＋Apps 基线 → `source/` → 相机 overlay；
语音开发树再应用语音 overlay。不要把语音 overlay 当作已验收相机版发布。

本次 Git 提交不包含 282 MB 的 `current-build-tree-source.tar.gz`、上游完整依赖归档、
ELF／BIN、摄像头照片、录音和本地服务密钥。原始基线归档 SHA256 为
`94a0ea4a8ef364a8d83b5dbbed106ed4a383e2f6052b64ebbb2af56f53df230d`。
HAL／LVGL／QuickJS／TLS 等仍需要匹配的外部基线和工具链；TLS 来源见
`diagnostics/downloads/tls-manifest.json`。

**这个 Git 快照不是已验证的全新 checkout 一键构建包。** 构建脚本记录的是
当前 WSL 隔离环境，含固定 `/tmp/` 和工具链路径，需要原有匹配基线。
`prepare_voice_work.py` 会复制相机隔离树，`refresh_voice_archives.py` 清理复制来的
构建依赖，`build_voice_tls.py` 使用 `-Os` 构建 TLS，`build_voice.py` 构建语音镜像。
继续开发必须先解决语音镜像体积问题，再做硬件采音、TLS、服务及界面验证。

相机原始 README／构建元数据保留本地交付时的证据文件名；Git 中只收录选定验证记录，
其中指向未导出的二进制、旧版本包、截图或构建树的路径不能视为 Git 已附带这些文件。

## 已有验证

相机：所附第 11 版串口记录覆盖预览、保存 JPEG、停止和重开；缓存验证记录确认
USB worker 调用了 P4 实际缓存写回函数。它们不证明所有摄像头或 CSI 已经通过。

语音：`evidence/host-test.log` 记录 ASan／UBSan 对 WAV、二进制 multipart、中文响应、
20,000 个异常输入，以及模拟采集／网络下重复请求、取消和失败阻断的测试。
Python WAV 与 MIME 解析器还独立验证了音频格式和上传字节。编译通过与这些测试
不能代替麦克风实际采音、转写质量、外部服务、TLS 或实板 UI 验收。
